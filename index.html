50 條 DAX 核心公式完整解析
資產負債表
公式01：期末資產負債表基礎金額
BS_Amount = SUM('F財務匯總表'[金額])
⚠️ 最基礎的求和。直接使用於時間切片器下會錯誤累加期末餘額，僅作中間度量值。
資產負債表
公式02：單位動態切換
BS_Unit = DIVIDE(SUM('F財務匯總表'[金額]),
  SELECTEDVALUE('D單位表'[倍率], 1))
透過「單位輔助表」實現元/萬元動態切換，SELECTEDVALUE返回切片器選中的倍率（1或10000）。
資產負債表
公式03：資產負債表正確期末額
BS_EndBalance =
LASTNONBLANKVALUE(
  'D日期表'[日期],
  CALCULATE([BS_Amount])
)
核心解決方案。LASTNONBLANKVALUE迭代日期列，返回最後一個非空值日期的計算結果，確保反映特定時點的期末餘額。
資產負債表
公式04：資產負債表年初數
BS_YearStart =
CALCULATE(
  [BS_EndBalance],
  FILTER(ALL('D日期表'),
    'D日期表'[年份] = YEAR(MAX('D日期表'[日期]))-1
    && MONTH('D日期表'[日期]) = 12
  )
)
定位至上一年度12月1日（系統默認月初），獲取該時點的期末數作為本年年初數。
資產負債表
公式05：資產增長額
BS_AssetGrowth =
[BS_EndBalance] - [BS_YearStart]
計算資產規模在會計期間內的絕對增減變動。
資產負債表
公式06：資產增長率
BS_AssetGrowthRate =
DIVIDE([BS_AssetGrowth], [BS_YearStart])
反映資產規模的擴張速度，DIVIDE安全除法，年初餘額為零時返回BLANK。
資產負債表
公式07：資產負債率
BS_DebtRatio =
DIVIDE([BS_TotalLiab], [BS_TotalAssets])
總負債÷總資產，衡量企業長期償債能力。正常範圍40%-70%，超過70%需警惕財務風險。
資產負債表
公式08：流動比率
BS_CurrentRatio =
DIVIDE([BS_CurrentAssets], [BS_CurrentLiab])
流動資產對流動負債的覆蓋倍數。標準值>2，最低安全線>1。低於1表示短期償債能力嚴重不足。
資產負債表
公式09：現金比率
BS_CashRatio =
DIVIDE([BS_Cash], [BS_CurrentLiab])
最嚴格的短期償債指標，僅考慮即時可動用的現金，標準值>0.2。
資產負債表
公式10：營運資本
BS_WorkingCapital =
[BS_CurrentAssets] - [BS_CurrentLiab]
反映企業短期內可自由動用的絕對金額。正值表示短期財務健康，負值需引起關注。
資產負債表
公式11：產權比率
BS_EquityRatio =
DIVIDE([BS_TotalLiab], [BS_TotalEquity])
反映債權人與股東提供資本的相對關係，越高說明負債越多，財務槓桿越大。
資產負債表
公式12：所有者權益總額
BS_Equity =
CALCULATE(
  [BS_EndBalance],
  FILTER('D科目表', '科目類型'="所有者權益")
)
精確定位負債與權益表中的權益合計項，用於資本結構分析。
資產負債表
公式13：平衡檢查
BS_BalanceCheck =
[BS_TotalAssets] - [BS_TotalLiab] - [BS_TotalEquity]
驗證建模邏輯是否正確，結果應恆等於0。若不為零，表示數據清洗或關聯存在問題。
資產負債表
公式14：資產端過濾（瀑布圖）
BS_AssetFilter =
IF(SELECTEDVALUE('D科目表'[序號])<=33,
  [BS_EndBalance], BLANK())
在矩陣視覺對象中使用序號過濾，將全表切割為資產端和負債端兩個獨立矩陣。
損益表
公式15：基礎金額（含單位切換）
IS_Base =
DIVIDE(
  CALCULATE(SUM('F財務匯總表'[金額]),
    FILTER('D科目表', '報表類型'="損益表")),
  SELECTEDVALUE('D單位表'[倍率], 1)
)
損益表的核心基礎度量值，同時集成單位切換邏輯。
損益表
公式16：借貸方向處理
IS_Signed =
[IS_Base] *
SELECTEDVALUE('D科目表'[方向係數], 1)
根據科目維度表中的方向屬性，收入類（貸方）保持正數，費用類（借方）轉為負數。
損益表
公式17：矩陣顯示（本期/金額組合）
IS_Matrix =
VAR _period = SELECTEDVALUE('輔助_期間'[期間])
VAR _type = SELECTEDVALUE('輔助_類型'[類型])
RETURN SWITCH(TRUE(),
  _period="本月"&&_type="金額", [IS_Signed],
  _period="本月"&&_type="佔比", DIVIDE([IS_Signed],[IS_Revenue]),
  _period="累計"&&_type="金額", CALCULATE([IS_Signed], DATESYTD('D日期表'[日期])),
  _period="累計"&&_type="佔比", DIVIDE(CALCULATE([IS_Signed],DATESYTD('D日期表'[日期])),CALCULATE([IS_Revenue],DATESYTD('D日期表'[日期])))
)
最複雜的核心公式。用VAR捕捉兩個切片器狀態，SWITCH(TRUE())實現四種組合邏輯。
損益表
公式18：淨利潤提取
IS_NetIncome =
CALCULATE([IS_Base],
  FILTER('D科目表',
    '科目簡稱'="淨利潤"))
從損益表中精確定位淨利潤行，用於趨勢圖和KPI計算的核心指標。
損益表
公式19：淨利率
IS_NetMargin =
DIVIDE([IS_NetIncome], [IS_Revenue])
淨利潤佔營業收入的比率，衡量企業最終盈利效率。
損益表
公式20：營業收入基準值
IS_Revenue =
CALCULATE([IS_Base],
  FILTER('D科目表',
    '科目簡稱'="營業收入"),
  ALL('D科目表'[科目名稱]))
確保佔比分析的分母統一，CALCULATE+ALL確保不受外部篩選器干擾。
損益表
公式21：同比差異額
IS_YoY_Diff =
[IS_Signed] - [IS_LYSPM]
分析各科目較去年同期的絕對增減值，直觀反映業績改善或惡化的規模。
損益表
公式22：同比差異率
IS_YoY_Rate =
DIVIDE([IS_YoY_Diff], ABS([IS_LYSPM]))
反映收入、費用等項目的同比增減幅度，百分比形式更直觀反映變動趨勢。
損益表
公式23：去年同期金額
IS_LYSPM =
CALCULATE([IS_Signed],
  SAMEPERIODLASTYEAR('D日期表'[日期]))
使用SAMEPERIODLASTYEAR函數將計算上下文偏移至去年同一時期。
損益表
公式24：本年累計（YTD）
IS_YTD =
CALCULATE([IS_Signed],
  DATESYTD('D日期表'[日期]))
// 等效：TOTALYTD([IS_Signed],'D日期表'[日期])
計算從年初至當前所選日期的累計發生額。兩種寫法完全等效，TOTALYTD更簡潔。
損益表
公式25：收入佔比
IS_RevenueShare =
DIVIDE(
  [IS_Signed],
  CALCULATE([IS_Revenue],
    ALL('D科目表'[科目名稱])))
ALL函數移除對科目表的所有篩選，再重新篩選僅保留營業收入，確保分母始終為總收入。
損益表
公式26：瀑布圖數據匹配（TREATAS）
IS_Waterfall =
CALCULATE(
  [IS_Signed],
  TREATAS(
    VALUES('輔助_瀑布'[關聯名稱]),
    'D科目表'[科目名稱]))
TREATAS在度量值內動態建立篩選路徑，讓輔助表控制主表，保持模型簡潔高效。
損益表
公式27：淨利潤 YTD 趨勢
IS_NetIncome_YTD =
CALCULATE([IS_NetIncome],
  DATESYTD('D日期表'[日期]))
展示淨利潤隨月份累加的趨勢，反映年度目標達成進度。
損益表
公式28：瀑布圖過濾（排除合計項）
IS_WF_Filter =
IF(
  SELECTEDVALUE('D科目表'[是否合計])=0,
  [IS_Signed],
  BLANK())
在瀑布圖中排除中間合計項（如「營業總成本」），防止重複計入。
現金流量表
公式29：期初餘額
CF_OpenBalance =
FIRSTNONBLANKVALUE(
  'D日期表'[日期],
  CALCULATE([CF_Base])
)
FIRSTNONBLANKVALUE獲取所選日期範圍內第一個非空日期的金額，與LASTNONBLANKVALUE形成對稱。
現金流量表
公式30：現金流量表顯示金額（混合邏輯）
CF_Display =
SWITCH(
  SELECTEDVALUE('D科目表'[資料類型]),
  "時點", FIRSTNONBLANKVALUE('D日期表'[日期], CALCULATE([CF_Base])),
  "期間", SUM('F財務匯總表'[金額]),
  BLANK()
)
結合FIRSTNONBLANKVALUE（期初）與SUM（活動流量）的核心混合邏輯，一個度量值同時正確處理所有現金流量項目。
現金流量表
公式31：支出符號修正
CF_Signed =
[CF_Display] *
SELECTEDVALUE('D科目表'[方向係數], 1)
專門針對現金流量表，將「支付」類貸方項目（現金流出）轉換為負數，收入類保持正數。
現金流量表
公式32：籌資活動淨額提取
CF_Financing =
CALCULATE([CF_Signed],
  FILTER('D科目表',
    '簡要名稱'="籌資活動淨額"))
利用簡要名稱字段精確提取現金流量表中的合計項數據，用於三大活動趨勢對比分析。
現金流量表
公式33：現金淨增加額
CF_NetChange =
CALCULATE([CF_Signed],
  FILTER('D科目表',
    '簡要名稱'="現金淨增加額"))

現金流量表
公式34：活動淨額同比
CF_YoY =
CALCULATE([CF_Signed],
  SAMEPERIODLASTYEAR('D日期表'[日期]))
專門針對三大活動淨額進行同比計算，在趨勢圖中同時展示本年與去年的活動淨額曲線。
現金流量表
公式35：淨流量 YTD
CF_NetYTD =
CALCULATE([CF_NetChange],
  DATESYTD('D日期表'[日期]))
反映自年初以來現金的淨流入/流出總量，用於全年現金頭寸管理。
現金流量表
公式36：投資活動貢獻度
CF_InvestShare =
DIVIDE([CF_Investing], [CF_NetChange])
分析投資活動對現金變動的影響程度，負值表示現金淨流出（投資支出）。
現金流量表
公式37：書簽視圖切換
CF_ViewSwitch =
SELECTEDVALUE('輔助_視圖切換'[視圖], "圖表")
通過DAX切片器聯動書簽，控制視覺對象的隱藏與顯示，實現「表格視圖」與「圖表視圖」動態切換。
現金流量表
公式38：現流瀑布圖輔助度量值

CALCULATE(

    VALUES('輔助_CF瀑布'[關聯名稱]),

現金流量表
公式39：瀑布圖自定義排序
CF_SortKey =
SELECTEDVALUE('輔助_CF瀑布'[序號])
創建度量值包裹序號列，確保現金流量表瀑布圖按準則順序：經營→投資→籌資→淨增加。
現金流量表

CF_ZeroFill =

FMT_Code =

公式42：動態報表名稱
DYN_Title =

公式43：流動比率預警（條件格式）
ALERT_CurrentRatio =

公式44：SWITCH 動態度量值（通用範本）
GEN_Switch =
VAR _sel1 = SELECTEDVALUE('切片器1'[值])
VAR _sel2 = SELECTEDVALUE('切片器2'[值])
RETURN SWITCH(TRUE(),
  _sel1="A" && _sel2="X", [度量值AX],
  _sel1="A" && _sel2="Y", [度量值AY],
  _sel1="B", [度量值B],
  BLANK())
SWITCH(TRUE())範本，組合多切片器狀態，相比嵌套IF更易讀且效率更高。
通用輔助
